# A Última Comporta — protótipo do prólogo

Jogo de aventura 2D para navegador. Este repositório guarda só a versão pronta para jogar (publicada no GitHub Pages).

Jogar: https://yurilucka.github.io/ultima-comporta/

Funciona no computador (setas ou WASD, E para interagir) e no celular deitado (direcional e botão Ação na tela).
